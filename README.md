本地小說企劃展示與整理臺

把你的小說資料夾，變成自己的創作工作臺。
Markdown、圖片、設定、篇章與 BGM 都留在本地。
不用安裝，不用帳號，也不用把作品搬進別人的雲端。
![畫面預覽](https://github.com/hflowerking/local-novel-project-showcase/blob/main/screenshots/home.png)
企劃、功能方向與版本整理：百花王 康門  
程式實作、文件整理與教學示例曾使用 OpenAI ChatGPT／Codex 協助完成，最終內容由百花王 康門選擇、修改與審訂。

完整解壓後，直接開啟 `index.html` 即可純瀏覽三個示例，不必選擇資料夾或授予權限。圖片可放大，BGM 需手動播放。

要整理自己的作品，使用桌面版 Chrome / Edge，點「連接本地企劃」並選擇包含 data、content、assets 的項目根目錄。授權後才會出現本地編輯與管理功能。「瀏覽示例」可返回唯讀示例；「恢復上次企劃」可重新授權已記住的資料夾。

**瀏覽器支援：**純瀏覽可使用一般現代瀏覽器；本地編輯與檔案管理僅支援桌面版 Chrome／Edge。

純瀏覽使用隨包示例快照；修改本地 Markdown 會在本地整理模式即時讀取。若要更新隨包示例，執行 `python build-demo.py`。此腳本會將 content 中的 Markdown 與 manifest 打包成 js/demo-data.js，分享前請確認內容均可公開。瀏覽器本身不需要安裝 Python。

先從左側《五分鐘上手》開始，再進入任一示例。三組內容分別展示世界觀管理、副本資訊管理及人物關係管理；十五份 MD 均包含短例子、表格、標籤與操作提示。文件名稱、分類和內容都可自行修改。

已有 Word／WPS 文稿時，不必先學習 Markdown。進入篇章後，把 `.docx` 拖到「匯入 Word／WPS 文稿」區域，或點文件夾旁的「＋DOCX」；工作臺會在瀏覽器本機抽取正文、基本標題、清單、表格、連結與內嵌圖片，再另存成 Markdown。原始 DOCX 不會被修改或上傳。

## 已知限制

- 本地編輯依賴 File System Access API，只支援桌面版 Chrome／Edge；手機、Firefox與 Safari 可使用純瀏覽。
- 瀏覽器基於安全規則不允許 BGM 自動播放，需要手動按播放。
- 純瀏覽內容是打包時生成的示例快照；修改示例 Markdown 後需重新執行 `python build-demo.py`。
- 大型企劃的全局搜索與字數統計會即時遍歷 Markdown，文件很多時可能需要稍候。
- DOCX 功能是單向匯入，不提供 DOCX 編輯、同步或匯出；舊版 `.doc` 不受支援。
- DOCX 的一般正文、標題、粗體、斜體、刪除線、清單、簡單表格、超連結與常見內嵌圖片可轉換；頁首頁尾、腳註、註解、修訂記錄、文字方塊及複雜版面不保證保留。匯入後應打開 Markdown 檢查一次。

驗證範圍：已檢查 JavaScript 語法、DOCX 文字／標題／清單／表格／連結／圖片匯入、五個公開刪除委託、安全刪除與 BGM／主題回歸、示例快照與素材路徑。
