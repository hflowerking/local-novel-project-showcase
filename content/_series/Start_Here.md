# 五分鐘上手

> 示例的任務不是證明我們會寫小說，而是教人怎麼用工作臺。三個項目只寫到足以看懂整理方法的程度；你可以直接修改、刪除，或把它們當成建立自己項目的參考。

## 第一步：連接資料夾

完整解壓後，開啟 `index.html` 就能純瀏覽三個示例，不需要授權。想開始整理時，用桌面版 Chrome 或 Edge 點「連接本地企劃」，選擇包含 `data`、`content`、`assets` 的項目資料夾。瀏覽器要求讀寫權限，是因為工作臺會直接保存你對 Markdown、圖片與設定所做的修改。

## 第二步：選一種整理方式

首頁有三個示例，各自展示一套不同的資料結構：

| 示例 | 主要示範 |
| --- | --- |
| 《逆爐問仙》 | 世界觀、硬規則、角色卡與篇章規劃 |
| 《第七碼頭》 | 副本規則、線索可信度、死亡條件與隊伍狀態 |
| 《春燈誤》 | 人物關係、感情進度、事件節點與伏筆回收 |

這些分類都不是固定欄位。你可以把「宗門人物」改成「角色」，把「副本規則」改成「案件規則」，也可以建立自己的資料夾。工作臺負責管理文件，不會限制你怎樣寫小說。

## 第三步：完成一次編輯

進入任一示例，打開一份 MD，點「編輯 Markdown」。試著改一句文字、加入二級標題或標籤，再按 `Ctrl+S` 保存。保存前的內容會自動進入 `_history`；若改壞了，可從「歷史版本」恢復。標籤寫在文檔頂端，形式如下：

```yaml
---
tags: [人物, 主角, 待確認]
---
```

標籤會出現在閱讀頁，也能配合全局搜索快速找回資料。

若原稿來自 Word 或 WPS，可以直接進入篇章，把 `.docx` 拖到「匯入 Word／WPS 文稿」區域。工作臺會在本機轉成 Markdown；原始 DOCX 不會被修改。一般正文、標題、清單、簡單表格、連結與常見內嵌圖片會盡量保留，複雜排版、修訂記錄、註解與頁首頁尾則需要匯入後人工檢查。

## 第四步：試用圖片與 BGM

進入「圖片庫」，可以把圖片設為封面、展臺圖、抬頭圖或插圖。封面出現在書架，展臺圖出現在首頁，抬頭圖會固定在篇章與閱讀頁上方。三個示例已各放入兩張原圖，方便直接觀察效果。

點右下角的 BGM 工具，選擇歌曲後按播放。進入不同示例時，工作臺會預選對應曲目；瀏覽器不允許自動播放，所以仍需手動按一次播放鍵。

右下角「🎨 主題」管理的是篇章類型與顏色。你可以新增「輕快」「戀愛」等類型，也可以替現有類型改名或換色。進入某個篇章後點「編輯篇章」，才是替該篇章更換類型；只調整顏色不會自動改變「恐怖懸疑」等名稱。

## 第五步：建立自己的內容

你可以先複製最接近自己需求的示例，再逐步替換名稱、MD、圖片與音樂；也可以直接在首頁按「新增篇章」建立空白結構。正式修改前，點右側的 `ZIP` 建立完整快照。刪除的文件會先進 `_trash`，不會立即永久消失。

> 建議第一次只做一個小動作：改掉作品名、重寫一張角色卡，再建立快照。完成這一輪後，你已經掌握工作臺最常用的流程。
