# 項目首頁

> 感情向作品容易累積大量氣氛片段，卻忘了人物關係為甚麼改變。這個示例用「關係階段＋事件證據」整理感情線。

| 項目 | 示例內容 |
| --- | --- |
| 作品名 | 《春燈誤》 |
| 類型 | 古風耽美、重逢、日常懸念 |
| 一句話簡介 | 書肆掌櫃謝珩與修書匠溫言因一封送錯的舊信重逢，兩人必須先弄清當年的誤會，才敢承認彼此都沒有忘記。 |
| 感情起點 | 客氣的舊識；兩人都以為對方曾主動斷聯 |
| 目前進度 | 重逢完成，準備進入共同修書事件 |

## 寫作承諾

- 兩位主角均為成年人。
- 誤會來自不完整資訊與各自選擇，不靠拒絕溝通硬拖篇幅。
- 每次關係升溫都要有具體行動支撐。
- 主線收束時，舊信的去向與兩人的選擇要同時得到回答。

> 這裡寫的是作品對讀者的承諾。甜度、章數等可調整項目另列為待定，不必太早鎖死。
